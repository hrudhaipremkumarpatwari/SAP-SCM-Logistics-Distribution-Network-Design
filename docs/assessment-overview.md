# Week 3 Assessment Overview — Logistics and Distribution Network Design in SAP SCM

## Assessment focus
This repository contains the Week 3 internship assessment on logistics and distribution network design in SAP SCM. The work evaluates distribution nodes, warehouse and dock constraints, inventory transfers, transportation choices, route efficiency, and network utilization.

## Repository standard
The six-assessment series uses a consistent structure: a root README, the final assessment and supporting analysis under docs/, and editable process diagrams under diagrams/. Where a structured dataset is useful, it is stored separately under data/.

## Scope note
This is an internship learning assessment. Network capacities, route assumptions, utilization changes, cost effects, and optimization results are illustrative unless supported by live system or operational evidence.
