# Route Optimization

## Baseline

The baseline scenario contains 12 weekly trips with approximately 78.1% modeled vehicle utilization.

## Optimization Approach

The simulation evaluates:

- Shipment consolidation
- Compatible destination grouping
- Vehicle-capacity utilization
- Delivery-window alignment
- Route sequencing
- Emergency replenishment requirements

## Modeled Result

After consolidation and route optimization:

- Weekly trips: **12 → 10**
- Vehicle utilization: **78.1% → 87.2%**
- Illustrative weekly transport cost: **₹1.78 lakh → ₹1.41 lakh**

The results are scenario calculations for learning and should not be interpreted as actual carrier quotations or live SAP results.
