## Week 3 Portal Submission Description

This Week 3 assessment presents a Logistics and Distribution Network Design analysis in SAP SCM using a practical internship simulation. The project examines how a distribution network can be designed to balance customer demand, warehouse capacity, staging space, dock availability, inventory positioning, transportation efficiency, and service requirements.

The scenario evaluates a network supporting approximately 150 tonnes per week and considers an illustrative warehouse capacity of 4,000 pallet positions, six dock doors, and controlled staging capacity. The analysis compares network and route decisions, reviews inventory-transfer logic, and examines how utilization changes when available capacity is used more effectively. The report includes distribution-planning analysis, route-optimization reasoning, inventory-transfer considerations, risk controls, and editable process diagrams.

The assessment focuses on the relationship between network design and operational execution. A theoretically low-cost route is not automatically the best choice if it increases transit risk, creates dock congestion, or weakens customer service. Therefore, the report evaluates cost, capacity, utilization, service, and operational feasibility together.

The repository is structured with the final Word assessment under docs/, supporting analytical notes, risk and validation documentation, and editable Mermaid diagrams under diagrams/. All network capacities, route assumptions, utilization percentages, savings, and optimization results are illustrative learning values. The assessment is a planning and configuration blueprint and does not claim live SAP execution or measured production results.
